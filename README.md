# SmartNotifications iOS16 Fixed

A fixed version of EliasSfeir's SmartNotifications for rootless iOS 16. Repairs settings that revert instead of saving by correcting preference-folder permissions and the All Apps settings path. The original tweak and fix install together as one package, without a separate companion tweak.

Original tweak by **EliasSfeir**; repair and packaging by **551UK**. To build your own merged DEB, use `sh scripts/build.sh /path/to/smartnotificationsios16_v1.0_iphoneos-arm64.deb ./dist` with a legitimately obtained original package. The original developer's proprietary binaries and source code are not included in this repository.
